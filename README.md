# Инструмент визуализации графа зависимостей для менеджера пакетов

CLI-приложение на Python для получения и визуализации графа зависимостей для менеджера пакетов.

## Общее описание

Реализованные этапы:

- Этап 1 - минимальный прототип CLI-приложения с конфигурацией.

Приложение принимает параметры командной строки, выводит их в формате ключ-значение и демонстрирует обработку ошибок при вводе неверных данных.

## Структура проекта

- `src/main.py` - точка входа;
- `src/.py` - разбор параметров командной строки;
- `tests/test_nuget.py` - тесты парсера;
- `run.sh` - запуск (Linux/macOS);
- `run.bat` - запуск (Windows);
- `README.md`
- `.gitignore`

## Настройка и параметры (Этап 1)

Источником параметров являются опции командной строки. Приложение поддерживает следующие аргументы:

| Параметр | Короткий | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `--package` | `-p` | *(обязательный)* | Имя анализируемого пакета |
| `--repo` | `-r` | `None` | URL-адрес репозитория или путь к тестовому репозиторию |
| `--mode` | `-m` | `remote` | Режим работы: `local` или `remote` |
| `--version` | `-v` | `latest` | Версия пакета |
| `--filter` | `-f` | `""` | Подстрока для фильтрации пакетов |

## Запуск приложения

**Linux / macOS:**

```
./run.sh -p Newtonsoft.Json -m local
```

**Windows:**

```
run.bat -p Newtonsoft.Json -m local
```

**Или напрямую через Python:**

```
py src/main.py -p Newtonsoft.Json
```

### Пример работы (Этап 1)

При запуске приложение выводит все параметры в формате ключ-значение:

```
py src/main.py -p Newtonsoft.Json -m local -f Json
Параметры запуска:
Имя пакета: Newtonsoft.Json
Репозиторий: (не указан)
Режим работы с тестовым репозиторием: local
Версия пакета: latest
Подстрока для фильтрации пакетов: Json
```

### Обработка ошибок

Если не указан обязательный параметр (`--package`), программа выдаст ошибку:

```
py src/main.py -m local
usage: main.py [-h] -p PACKAGE [-r REPO] [-m {local,remote}] [-v VERSION] [-f FILTER]
main.py: error: the following arguments are required: -p/--package
```

Если указан неверный режим (`--mode`), программа также корректно обработает ошибку:

```
py src/main.py -p Test -m invalid
main.py: error: argument -m/--mode: invalid choice: 'invalid' (choose from 'local', 'remote')
```

## Запуск тестов

Для проверки работоспособности модуля разбора параметров написаны тесты:
